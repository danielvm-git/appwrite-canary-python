## 1. Business narrative [locked]

Vertical slice for python.danielvm.net. Version numbers are produced only by big-release after Conventional Commits (see https://semver.org/lang/pt-BR/). This story specifies commit type `feat:` not a target version.

## 2. Value statement [locked]

As a **visitor**, I want **Hello World and the current release version on python.danielvm.net**, so that **deploy matches the git tag**.

## 3. Actors and permissions [locked]

Visitor (read); maintainer (push, secrets); GitHub Actions.

## 4. Trigger and preconditions [locked]

Pre: [`host-preflight`](../../../specs/platform/host-preflight.yaml) layer 1 passing; layer 2 Site+secrets for this repo.

## 5. Main flow and business logic [locked]

1. Squash-merge one `feat:` commit (beta prerelease staging python) to `main`.
2. TBR runs; big-release writes VERSION and tag from commit type.
3. CI job `preflight` → `build` → `deploy` → `smoke`.
4. Visitor loads https://python.danielvm.net/; UI shows VERSION from release artifact.

**Interruption point:** preflight fails → deploy job skipped.
